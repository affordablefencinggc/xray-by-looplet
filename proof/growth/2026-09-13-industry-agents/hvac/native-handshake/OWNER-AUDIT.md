# Windows private-directory owner audit

Read-only review2026-09-13. Current create_private_directory SDDL sets a protected DACL but omits O:, while windows_security_tests.rs asserts the resulting owner equals process TokenUser. Microsoft distinguishes TokenUser (user account) from TokenOwner (default owner for newly created objects): https://learn.microsoft.com/en-us/windows/win32/api/winnt/ne-winnt-token_information_class . A differing default owner is therefore consistent with the elevated SSH failure; the actual baseline result remains HVAC/root evidence, not independently executed here.

Smallest directory-scoped fix: construct `O:<TokenUser SID>D:P(A;OICI;FA;;;OW)(A;OICI;FA;;;SY)` before CreateDirectoryW. O: sets owner; D:P protects the DACL: https://learn.microsoft.com/en-us/windows/win32/secauthz/security-descriptor-string-format . OW means Owner Rights, not the current user account: https://learn.microsoft.com/en-us/windows/win32/secauthz/sid-strings .

Use OpenProcessToken(GetCurrentProcess(),TOKEN_QUERY), two-pass GetTokenInformation(TokenUser), then ConvertSidToStringSidW. Query-buffer storage must satisfy TOKEN_USER alignment and remain alive while its SID is read. Check each API result and preserve last error before cleanup. Close token handles and LocalFree converted SID/security-descriptor allocations on every exit. ConvertSidToStringSidW allocation contract: https://learn.microsoft.com/en-us/windows/win32/api/sddl/nf-sddl-convertsidtostringsidw . Supply security attributes during creation, not a permissive create followed by ACL repair; fail closed without default-ACL fallback.

Expected existing assertions remain: owner EqualSid TokenUser, SE_DACL_PROTECTED, exactly the two OW/SY full-access inheritable ACEs, and cleanup. This fixes the DIRECTORY owner identity only. Inherited OW applies to each child's owner; directory owner equality does not prove child-file user ownership under elevated creation. It is not protection against privileged administrator/LocalSystem control. Do not broaden the directory-only evidence into a whole-sandbox isolation claim.
