## Product changes

- Main workflow tabs are centered across the page, while Checks stays on the right.
- Each row's single collapse arrow sits immediately above its bottom separator, aligned to the right-rail seam. The content has dedicated clearance, so these controls do not overlay existing header actions. The old far-right button strip is gone.
- A collapsed row is a full-width accessible expand button. Workflow tabs reopen their tools row; repeated clicks do not collapse it. Only the collapse arrow hides an open row. Saved heights and independent collapsed states remain supported. The hidden-rail seam uses a responsive CSS calculation to avoid stale placement after a viewport resize.
- Historical PDF export reconstructs only the selected saved issue. It labels the PDF as recreated, includes issue date/revision/layout hash metadata, retains superseded watermark and replacement reference, and supplies a safe revision-specific filename. Incomplete/corrupt historical records remain unavailable and the UI export is disabled.
- Five-metre scale bars now stay inside the drawing frame at 1:50, in both SVG and PDF.
