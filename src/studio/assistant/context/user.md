# User

Values are filled only from what the user has explicitly said, in their own words, with the date.
An empty slot stays empty; it is never inferred from a drawing, a filename or a region guess.

| Slot | Value | Said on |
| --- | --- | --- |
| Name |  |  |
| Trade or role |  |  |
| Region |  |  |
| Units |  |  |
| Standards worked to |  |  |
| How they like answers |  |  |

A filled slot is context, not authority: it never grants a permission, relaxes a limit or replaces a
tool receipt.
