## Closure rule

- IDs are immutable and ordered by the source crosswalk rows: `FC-011` through `FC-043`.
- Every row is pending. `FC-023` through `FC-027`, `FC-031` through `FC-033`, `FC-038` through `FC-040`, and `FC-043` are decision-gated.
- A rejected decision is accepted only with machine proof that the capability is unreachable and human proof that the product describes it truthfully. An approved decision expands the named build and proof requirements before implementation.
- No existing binary, sidecar, installer, network endpoint, committed test label, or source file satisfies these rows by presence alone.
