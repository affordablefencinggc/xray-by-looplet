The 461 entrance allowance is an inference from the accommodation counts. It is not a verified count of door symbols, leaves, frames, fire-rated doors or complete supply assemblies. Internal unit doors and all other floors are excluded. Earlier EDG 2 inset plans are excluded. Floors 8-30 and 44-48 give 28 residential repetitions; 33-43 gives 11 hotel repetitions.

The running app now displays these groups in Components when the actual Altitude drawing is selected. Each group has page navigation, floor lists, assumptions, unresolved specifications, editable per-floor count with required change note, review state and revision. Save group persists edits in a project- and source-bound takeoff inventory. Unreadable/future snapshots block writes; cross-tab changes prevent stale overwrites. The earlier demo physical-component graph is retained separately.

Packaging volume uses ceil(quantity / counted items per package) x package length x width x height in metres. Specified weight uses quantity x specified kg per counted item. A supplier/specification reference is required for entered stock data. Known subtotals and group coverage are shown; blank values remain unknown and aisle/handling space is excluded. Test packaging used for verification is not part of the actual source inventory.

Real whole-building material quantities, storage m3 and weight are still unknown. Required next sources: door/window schedules, structural plans/legend/member and connection schedules, and supplier packaging/weights. A full tower reconstruction also needs coordinated levels and dimensions; this work does not create a 3D model.
